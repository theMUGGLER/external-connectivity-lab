# Security policy

This project is a lab infrastructure template for authorized security testing.

Do not include private keys, Terraform state, AWS credentials, live infrastructure addresses, or client evidence in a public issue. For sensitive reports, use a private contact method listed on the maintainer's GitHub profile, or GitHub private vulnerability reporting if enabled for this repository.

Include the affected commit, a sanitized description, reproduction steps in a lab you control, impact, and a suggested fix if available. Non-sensitive documentation and configuration issues can be reported through ordinary GitHub issues.

No formal support window or response-time guarantee is provided. Verify effective host configuration and cloud access controls before each deployment.
